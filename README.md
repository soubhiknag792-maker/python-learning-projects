# Learn Python with Projects

An interactive, project-based Python learning dashboard for learners progressing from complete beginner to advanced Python.

## Start Learning

[Open the interactive dashboard](https://soubhiknag792-maker.github.io/python-learning-projects/)

## What You Will Learn

- Python syntax, variables, data types, and operators
- Conditions, loops, functions, and scope
- Strings, lists, tuples, dictionaries, and sets
- Files, JSON, CSV, exceptions, modules, and command-line programs
- Classes, dataclasses, testing, debugging, logging, and type hints
- Generators, decorators, context managers, regular expressions, SQLite, APIs, and automation
- Foundations of threading, multiprocessing, and asynchronous programming

## Included Features

- Five guided learning paths
- Twenty-six structured lessons
- Knowledge checks with immediate feedback
- Eight practical Python project guides
- Searchable syntax and function references
- Local progress tracking
- Import and export of learning progress
- Light and dark themes
- Offline-compatible dashboard

## Learning Approach

Each lesson introduces the syntax and Python functions needed to build a practical project. Learners attempt meaningful work, use progressive hints, complete knowledge checks, and track their progress.

## Privacy

The dashboard runs entirely in the browser. Learning progress is stored locally on the learner's device and is not uploaded to a server.

## Important Note

The dashboard teaches and guides Python development, but it does not execute Python code. Learners run their projects using their own Python installation and development environment.
